# 記事の写真 / Journal images

記事の `slug` と同じ名前のファイルを置くと、自動的にヒーロー画像になります。

    foundation-that-disappears.jpg    ← slug が foundation-that-disappears の記事

- `.jpg` と `.png` が使えます
- 写真が無い記事は、自動生成のイラストが表示されます
- **横長**が向いています（目安 1600×1000px、たて5：よこ8くらい）
- 顔は写さない方針は記事写真も同じです
- 1枚 400KB 以下が目安

Name the file after the article's slug and it becomes that story's hero image.
Articles without a photo keep their generated artwork.
